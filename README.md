# Arena Breakout

## Descripción

Página web informativa sobre el videojuego Arena Breakout.

## Tecnologías

- HTML
- CSS
- JavaScript

## Requisitos

- Navegador web
- Editor de código

## Instalación

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir `index.html` en un navegador.

## Uso

La página permitirá conocer información relacionada con Arena Breakout.
